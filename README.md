# Vibe Hackathon Platform

Vue 3 + Vite 기반 해커톤 플랫폼 데모 웹앱입니다.  
해커톤 탐색부터 팀 결성, 제출, 리더보드, 알림까지 하나의 흐름으로 체험할 수 있도록 구성되어 있습니다.

## 배포 주소

- https://hackathon-app-kappa.vercel.app/

## 1. 프로젝트 소개

이 프로젝트는 **실전형 해커톤 운영/참가 시나리오**를 프론트엔드만으로 빠르게 검증하기 위한 데모입니다.
또한 [월간 해커톤 : 긴급 인수인계 해커톤 - 문서만 남기고 사라졌다](https://daker.ai/public/hackathons/monthly-hackathon-emergency-handover-docs?section=leaderboard)의 콘셉트처럼, **예시 문서(제공 자료)만 남기고 사라진 개발자의 기록을 바탕으로 바이브 코딩으로 웹서비스를 구현·완성하고 Vercel로 배포하는 해커톤**을 위해 만든 프로젝트라는 맥락도 담고 있습니다.

- 참가자 관점: 대회 탐색, 북마크, 팀 합류 신청, 제출 현황 확인
- 팀장 관점: 팀 생성, 모집 포지션 관리, 가입 신청 승인/거절
- 운영자 관점: 운영자 계정 로그인 후 제출 관련 추가 정보 확인
- 공통: 로컬 스토리지 기반 상태 유지(세션, 북마크, 팀/제출/알림 데이터)

## 2. 핵심 기능

### 홈/탐색

- 홈 대시보드 KPI(진행/예정 대회, 모집 중 팀, 프로젝트 수 등)
- 해커톤 목록 필터링
  - 상태(진행중/예정/종료)
  - 검색어
  - 태그
  - 북마크(찜)만 보기
  - 정렬

### 해커톤 상세

- 개요/안내, 평가, 일정, 상금 섹션 제공
- 규정/FAQ 링크 노출
- 일정 `.ics` 캘린더 파일 다운로드
- 로그인 사용자를 위한 북마크 토글
- 해당 해커톤 팀/제출/리더보드 연계

### 팀 캠프(모집/합류)

- 팀 모집글 생성(포지션별 인원 설정 포함)
- 팀 상세에서 모집 상태/마감 여부 확인
- 팀 가입 신청(포지션 + 메시지)
- 팀장(팀 소유자)의 가입 신청 승인/거절

### 리더보드/프로필/알림

- 글로벌 랭킹(전체/최근 7일/최근 30일)
- 해커톤별 리더보드(검색/정렬)
- 내 프로필에서
  - 누적 포인트
  - 내 팀
  - 내가 보낸 가입 신청 상태
  - 북마크 목록
  - 읽지 않은 알림 수 확인
- 알림함에서 읽음/전체 읽음 처리

### 인증/권한

- 일반 사용자: 회원가입/로그인
- 운영자: 분리된 운영자 로그인 탭
- 보호 라우트: `/me`, `/notifications`는 로그인 필요

## 3. 기술 스택

- **Framework**: Vue 3 (`<script setup>`)
- **State**: Pinia
- **Router**: Vue Router
- **Build Tool**: Vite
- **Data Source**: `public/data/*.json` + localStorage

## 4. 디렉터리 구조

```bash
.
├─ public/
│  ├─ data/                      # 공개 목업 데이터(JSON)
│  └─ ...                        # 아이콘/브랜드/매니페스트 등 정적 파일
├─ src/
│  ├─ components/                # 공통 UI 컴포넌트
│  ├─ views/                     # 페이지 뷰
│  ├─ stores/                    # Pinia 스토어(auth, hackathon)
│  ├─ router/                    # 라우트 정의 + 로그인 가드
│  ├─ utils/                     # 날짜/시간 유틸
│  ├─ constants/                 # 포지션 옵션 등 상수
│  ├─ App.vue
│  └─ main.js
├─ index.html
├─ package.json
└─ vite.config.js
```

## 5. 시작하기

### 1) 의존성 설치

```bash
npm install
```

### 2) 개발 서버 실행

```bash
npm run dev
```

기본 주소: `http://localhost:5173`

### 3) 프로덕션 빌드

```bash
npm run build
```

### 4) 빌드 결과 미리보기

```bash
npm run preview
```

## 6. 라우트 맵

- `/` : 홈
- `/hackathons` : 해커톤 목록
- `/hackathons/:slug` : 해커톤 상세
- `/hackathons/:slug/leaderboard` : 특정 해커톤 리더보드
- `/rankings` : 글로벌 랭킹
- `/teams` : 팀 목록/모집
- `/teams/:teamCode` : 팀 상세
- `/camp` : `/teams` 리다이렉트
- `/auth` : 로그인/회원가입
- `/me` : 내 프로필 (로그인 필요)
- `/notifications` : 알림 (로그인 필요)
- `/:pathMatch(.*)*` : 404

## 7. 인증/데모 계정

### 운영자 계정 (데모)

- 아이디: `admin`
- 비밀번호: `admin1234`

> 운영자 계정은 데모 편의를 위한 하드코딩 계정입니다. 실제 서비스에서는 서버 인증/권한 체계로 대체해야 합니다.

## 8. 데이터/상태 저장 방식

- 초기 공개 데이터: `public/data/*.json`
- 사용자/세션/북마크/팀 변경사항/알림 읽음 여부: 브라우저 `localStorage`
- 백엔드 API 없이도 주요 사용자 플로우를 확인할 수 있도록 설계

## 9. 참고 사항

- 이 프로젝트는 데모/프로토타입 성격이며, 보안/검증/권한/데이터 무결성은 운영 환경 기준으로 강화가 필요합니다.
- 제출 링크, 팀 연락처 등 외부 URL은 실제 서비스 적용 시 검증 로직 추가를 권장합니다.
